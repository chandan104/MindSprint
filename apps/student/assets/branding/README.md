# Skill Lab branding assets

Save the app logo here as **`skill_lab_logo.png`** in this folder:

    apps/student/assets/branding/skill_lab_logo.png

Requirements:
- Square PNG, at least **1024×1024**.
- Transparent or white background (the launcher config uses a white adaptive
  background).

Once the file is in place:
1. `flutter pub get`
2. `dart run flutter_launcher_icons`  → regenerates the Android launcher icon.

The same file is also shown on the login and splash screens.
